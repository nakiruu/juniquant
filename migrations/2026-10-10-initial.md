# Migration: initial lake layout and pre-first-write corrections

- Date: 2026-10-10
- Author: nakiruu
- Type: initial (pre-first-write; no dataset had been written)
- Affected datasets: all 35 (`13-parquet-lake/SKILL.md` §3)

## Change

Corrections made in place before the first write (`13-parquet-lake/SKILL.md`
§1, `MIGRATIONS.md`). From the first write of a dataset, its schema is frozen.

| Dataset | Correction |
|---|---|
| #1 `universe` | Rewritten as a daily membership table, one row per `(date, ticker)`. Removed `etf_source` (now `in_iwf`/`in_iwp`), `effective_date`/`end_date`, `data_years` (now `history_days`), the current-only `eligible` flag and the `delisted` reason |
| #2 `prices` | Raw as-traded OHLCV. `adj_close` replaced by the diagnostic `adj_close_vendor`; `source`, `fetched_at`, `raw_sha256` appended |
| #3 `fundamentals` | One row per `(ticker, accession)`; primary key was `(ticker, filing_date, form_type)`. `accession` and the following columns appended |
| #4 `macro` | Long form with ALFRED vintages (`known_from`); the earlier wide table is a query |
| #5 `panel` | `label_flag_63d`, `label_flag_126d`, `label_flag_252d` appended (21 columns) |
| #10 `evt_tail_bounds` | Single file became `P(year)` |
| #19 `evaluation_metrics` | Merge key `(run_id, track, path_id, fold, eval_date, horizon, spread_source)` with nulls comparing equal (`IO-CONTRACT.md` §3) |
| #20 `data_quality` | Primary key was `(date, source, dataset)`, now `(date, source, dataset, entity, chunk, check_id, run_id)`; those columns and `attempts`, `measured`, `threshold` appended |
| #28-#35 | Added: `splits`, `dividends`, `etf_holdings`, `security_master`, `delistings`, `filing_events`, `price_coverage`, `listings` |
| #31 `security_master` | Redefined 2026-10-11 (DECISIONS D17): keyed by US composite FIGI instead of ticker; `figi`, `share_class_figi`, `eodhd_code`, `delisted`, `security_type`, `figi_name` added; `share_class`, `vendor_symbol`, snapshot dates and `prior_tickers` removed (the dated identifiers are in #36) |
| #36 | Added 2026-10-11: `security_spells` (D17) |
| #30 `etf_holdings` | 2026-10-11 (D17): `figi` appended (nullable) |
| #2 `prices`, #28 `splits`, #29 `dividends` | 2026-10-11 (D17): `figi` added as the first column and the key is `(figi, date)` / `(figi, ex_date)`; `ticker` is now the canonical form of the EODHD code, not a key. The eight-code W5 test run written under the old key was deleted and rebuilt from the landing zone |
| #5 `panel` | 2026-10-11 (D18): four candidate columns appended, not features: `log_mcap`, `r_size`, `amihud_60d`, `r_amihud` |
| #1 `universe`, #5 `panel` | 2026-10-11 (D20), before first write: `universe` holds every in-scope security with a price, keyed `(date, figi)` (`figi` added after `date`; `snapshot_date`, `snapshot_age_days` nullable; `no_price_data` and `identity_unresolved` reasons dropped). `panel` appends `figi` and is keyed `(figi, date)` (26 columns) |
| All partitioned | Leaf name `data.parquet` everywhere (was a mix of `data.parquet`, `part.parquet`, `part-YYYY-MM-DD.parquet`; `IO-CONTRACT.md` §2) |

Registry: `schemas/registry.json` is format_version 2. Each entry carries
`fields`, `primary_key`, `sort_key`, `merge` and `partition_column`
(`13-parquet-lake/SKILL.md` §6); every entry has `last_migration =
2026-10-10-initial`.
